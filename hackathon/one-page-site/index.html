The trust gap in AI robotics

Robots are getting smarter, but identity, payments, audit trails, and safety approvals remain fragmented across proprietary logs and manual workflows.

Identity is weak

Operators need to verify which robot, model, plugin, and policy approved a command.

Services are hard to pay

Robots need specialist APIs for vision, mapping, diagnostics, and maintenance without manual billing.

Actions need gates

Physical movement deserves the same explicit approval posture OpenClawd already applies to swaps and mints.

OpenClawd Robotics Command Layer

The existing financial AI agent stack becomes a robotics layer by mapping wallets to robots, MCP tools to capabilities, and attestations to command receipts.

On-chain robot identity

Wallet, ACP record, Metaplex Core asset, and Solana Attestation Service receipts.

Telemetry memory

Sensor facts enter KNOWN memory, hypotheses enter INFERRED memory, validated patterns become LEARNED.

Paid autonomy

x402 and plugin.delivery let robots pay per call for specialist services while keeping commands auditable.

Self-evolving trading loops

OpenClawd turns market research into a bounded ratchet: propose one strategy change, run a paper experiment, score it, persist the result, and keep only validated improvements.

Percolator lanes

Research, paper trading, risk review, and live execution stay isolated like parallel Solana trading lanes.

Autoresearch ratchet

Inspired by Karpathy's loop: fixed-budget experiments, objective scoring, promote winners, retire failures.

Honcho persistence

Durable memory preserves strategy lineage, operator risk preferences, and lessons from prior runs.

observe -> research -> simulate -> score -> ratchet -> persist -> gated execution

Offline demo flow

A warehouse robot detects a hazard, blocks unsafe motion, requests a paid diagnostic plugin, runs a paper-trading research pass, and emits a verifiable receipt.

ObserveLidar obstruction, thermal spike, vibration anomaly.
OrientClassify readings into memory tiers and infer elevated risk.
DecideGenerate a limited command plan: reverse slowly, capture image, alert operator.
ActPolicy allows limited movement and creates an x402 payment intent for a thermal diagnostic plugin.
EvolvePaper-trade candidate strategy is scored and promoted only if it beats the current champion.
ProveReceipt includes hashes for telemetry, policy, command, payment intent, and autonomous research state.
