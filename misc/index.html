Install in 60 seconds

Pick whichever surface you want. Both ship as published npm packages.

🦞

clawd — the Solana TUI

Birdeye + Helius DAS, on-paste contract cards, OpenRouter-native agent under the hood.

$ npm i -g @openclawdsolana/clawd-tui
$ clawd
🦀

clawd-code — the full Ink agent

Multi-provider AI (Grok / Claude / OpenRouter / Ollama), MCP, voice I/O, multi-agent panes.

$ npm i -g @openclawdsolana/clawd-code-cli
$ clawd-code
# Or bootstrap the entire stack — Go runtime, framework, gateway, plugin.delivery
$ curl -fsSL https://install.solanaclawd.com | bash

Solana data keys are auto-loaded from ./.env, ~/.clawd.env, or ~/.config/openclawd/.env. Set BIRDEYE_API_KEY and HELIUS_API_KEY. Either alone unlocks the relevant features; both is best.

Eleven commands. Two backends. Zero context switches.

Birdeye covers prices, trending, and wallet portfolio values. Helius DAS handles single-asset lookups, NFT collections, holder distribution, and on-chain transaction history.

The stack

Three layers that compose. Each one publishable. Each one usable on its own.

🦞

clawd-tui

The Solana-aware terminal. Paste a mint, get a card. Eleven slash commands. OpenRouter-native agent loop with file/glob/grep/shell tools.

🐦

ClawdBot

Autonomous X + Telegram agent. Tweets every 10 minutes. Retweets @clawddevs. 46+ slash commands for anyone the bot follows.

🦞

Leviathan

The on-chain sovereign-agent runtime. Every leviathan owns its keypair, earns its USDC, spawns its own brood, beaches when it stops paying.
