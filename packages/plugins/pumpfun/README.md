# Pump.fun OpenClawd Plugin

Create and buy tokens on [Pump.fun](https://pump.fun/).

## Installation
```
npm install @openclawdsolana/plugin-pumpfun
yarn add @openclawdsolana/plugin-pumpfun
pnpm add @openclawdsolana/plugin-pumpfun
```

## Setup

```typescript
import { pumpfun } from "@openclawdsolana/plugin-pumpfun";

const tools = await getOnChainTools({
    wallet: // ...
    plugins: [
        pumpfun(),
    ],
});
```

## Tools
- Create and buy the created token
