# Meteora OpenClawd Plugin

Create positions on [Meteora](https://meteora.ag/).

## Installation

```bash
npm install @openclawdsolana/plugin-meteora
yarn add @openclawdsolana/plugin-meteora
pnpm add @openclawdsolana/plugin-meteora
```


## Usage

```typescript
import { meteora } from "@openclawdsolana/plugin-meteora";

const tools = await getOnChainTools({
    wallet: // ...
    plugins: [
        meteora()
    ]
});
```

- Create positions
