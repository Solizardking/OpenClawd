# Tensor OpenClawd Plugin

Buy NFTs on [Tensor](https://www.tensor.trade/).

## Installation
```
npm install @openclawdsolana/plugin-tensor
yarn add @openclawdsolana/plugin-tensor
pnpm add @openclawdsolana/plugin-tensor
```

## Usage
```typescript
import { tensor } from "@openclawdsolana/plugin-tensor";

const tools = await getOnChainTools({
    wallet: // ...
    plugins: [tensor()],
});
```

## Tools
- Get NFT info
- Buy NFT
