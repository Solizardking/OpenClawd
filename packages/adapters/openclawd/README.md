# OpenClawd Adapter for OpenClawd

Integrate the more than +200 onchain tools of OpenClawd with [OpenClawd](https://openclawd.ai).

## Installation
```
npm install @openclawdsolana/adapter-openclawd
yarn add @openclawdsolana/adapter-openclawd
pnpm add @openclawdsolana/adapter-openclawd
```

## Usage

See a full working example [here](https://solanaclawd.com).
