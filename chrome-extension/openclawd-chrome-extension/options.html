OpenClawd Browser Bridge

CDP relay · Gateway client · Solana agent wallet — all in one extension.

1. CDP Relay automation

Click the toolbar button on any tab to attach Chrome's debugger and bridge it to a local OpenClawd CDP relay. If the badge shows a red !, start the relay first.

Default 18792. Connects to http://127.0.0.1:<port>/.

2. OpenClawd Gateway market data

Where the extension fetches token cards (Birdeye + Helius DAS) when you right-click a Solana address. Defaults to a local dev gateway on http://127.0.0.1:8788.

For prod use https://gateway.solanaclawd.com.

3. Solana Agent Wallet on-chain

A Solana keypair that lives encrypted (AES-GCM) inside chrome.storage.local. Auto-locks after 15 min of inactivity. The private key never leaves this extension.

How they fit together

🦞 Click toolbar → CDP relay attaches the active tab.
🦞 Right-click any Solana address on a page → "Look up in OpenClawd" calls the Gateway and shows a notification.
🦞 The wallet signs Solana transactions the Gateway hands back (e.g. Jupiter swaps you initiated from the page).
