### Current install / handoff commands

```bash
# TUI immediately, no global install
npx -y @openclawdsolana/clawd-tui

# Install both the TUI and code CLI
npm install -g @openclawdsolana/clawd-tui @openclawdsolana/clawd-code-cli

# Enter the TUI
clawd

# Enter the code-focused CLI
clawd-code

# Curl installer for both packages
curl -fsSL https://install.solanaclawd.com | bash

# User-prefix fallback for locked-down npm global installs
curl -fsSL https://install.solanaclawd.com | bash -s -- --prefix "$HOME/.local"
```

- pre-commit hook: blocks commits with staged secrets
- pre-push hook: runs hygiene checks before pushing

**`scripts/doctor.mjs`**
- Verifies bootstrap requirements
- Checks: Node.js version (20+), package.json, README.md, LICENSE, .gitignore, AGENTS/, skills/, scripts/

**`scripts/guard-secrets.mjs`**
- Scans codebase for leaked credentials
- Detects: OpenAI keys, OpenRouter keys, private key blocks, Slack/GitHub/AWS tokens
- Excludes known-safe patterns:

  - `AKIAIOSFODNN7EXAMPLE` (AWS example key)
  - `c8a8aaeb7ef3fbcce40bada2196e2bcb` (known example hash)
  - `0bc83cb571cd1c50ba6f3e8a78ef1346` (Gravatar example MD5)
- Can run on `--staged` or `--worktree` files

**`scripts/brand-check.mjs`**
- Catches old brand references in docs
- Checks for: openclawd, openclawdsolana, clawdhub, openclawd, clawd3d

**`scripts/release-check.mjs`**
- Public-release hygiene verification
- Checks: package.json metadata, README content, LICENSE, .gitignore, .env protection, catalog files
